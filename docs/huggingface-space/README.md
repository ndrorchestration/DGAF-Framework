## DGAF — Governed Agent Proof of Operation

This Static Space is a presentation layer for **Dynamic Governance Agentic Formation (DGAF)**.

It does not execute DGAF governance logic and it does not create authority. Its purpose is to give evaluators a concise entrypoint into the accepted public proof-of-operation.

## Start here

1. Open the **[live DGAF proof-of-operation](https://project-7ybao.vercel.app/demo)**.
2. Run **Allowed action** and confirm an execution receipt with a verified postcondition.
3. Run **Revoked authority** and confirm `AUTHORIZATION_REVOKED` with no execution receipt.
4. Return here for the evidence identity and claim ceiling.

## What the demo shows

`REQUEST → AUTHORITY → ADMISSION → EFFECT → RECEIPT → CLAIM BOUNDARY`

The core distinction is that capability, evidence, verification, authority, and permission remain separate states.
