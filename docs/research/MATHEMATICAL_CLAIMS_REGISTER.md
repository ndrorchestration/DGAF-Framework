## Purpose

This register prevents mathematical language, structural properties, analogies, and empirical claims from being conflated across DGAF/PDMAL and related projects.

It is not a substitute for each project's canonical evidence or control-state authority. Each row is deliberately scoped and conservative.

## Register rules

1. A project may cite this register for classification discipline, but its own canonical evidence controls project-specific truth.
2. New rows must preserve exact scope and must not import evidence from adjacent projects.
3. A classification change requires an evidence reference and date.
4. `MATHEMATICAL_PROPERTY` rows must identify the exact mathematical object elsewhere in the evidence chain.
5. `EMPIRICALLY_SUPPORTED` must never be assigned solely from implementation, simulation smoke tests, external literature, or mathematical plausibility.
6. Post-hoc discoveries remain exploratory until tested on fresh/held-out data under a prospective plan.
7. Negative findings remain in the evidence chain.
8. “Harmonic,” “resonant,” “phi,” “spectral,” and similar terms must be interpreted literally only where a defined mathematical model warrants it.
