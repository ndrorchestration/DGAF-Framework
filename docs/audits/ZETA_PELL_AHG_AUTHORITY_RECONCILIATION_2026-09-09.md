## Scoped concepts retained

The blueprint contains engineering ideas that may remain useful as **research candidates** when operationalized independently of the unsupported Zeta/Pell guarantees:

1. **Sidecar telemetry** — collect observable runtime signals without giving the monitor unilateral scientific or authorization authority.
2. **State estimation** — estimate a declared operational state from explicit observables, with calibration/error characterization.
3. **Bounded actuation** — define permitted controller actions, authority, rate limits, rollback, and fail-closed boundaries.
4. **Disturbance injection** — test behavior under controlled perturbations instead of assuming stability.
5. **Anchor/recovery testing** — evaluate whether a system returns to an explicitly identified valid state after perturbation.
6. **Controller/worker separation** — keep observation, decision, actuation, and evidence roles distinguishable and attributable.
7. **Comparator-based evaluation** — compare a proposed Kalman/MPC/sidecar controller with simpler baselines before attributing benefit to Zeta-Pell geometry.

These candidates should map to current owning contracts/evaluators rather than create a second governance stack.
