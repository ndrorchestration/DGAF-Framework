## Purpose

The first public-facing read of DGAF should answer two questions quickly:

1. what problem the system solves;
2. what it is **not** currently entitled to claim.

The interface therefore pairs a concise value proposition with an explicit
claim ceiling rather than hiding scientific uncertainty behind product polish.

## External summary

The Overview now describes DGAF in three operational verbs:

- **Govern actions** — make admissible transitions explicit before execution;
- **Bind evidence** — attach claims to provenance, verification scope, and
  immutable records;
- **Expose limits** — show what is not authorized, not established, or not yet
  reachable.

This wording is intentionally less repository-internal than the surrounding
operator surfaces while remaining faithful to the same semantics.

## Current scientific wording boundary

Public copy must now reflect that Track A Epoch 002 locked primary analysis has executed and its result receipt is established, while interpretation/adjudication remains not established. Public copy must not describe primary analysis as pending, and it must still preserve canonical efficacy `NOT ESTABLISHED`, independent validation `NOT ESTABLISHED`, scientific-N increment 0, and High-Assurance `NOT AUTHORIZED`.

## Claim ceiling

The external summary renders `TRUTH_BOUNDARY.efficacy` directly beside the
value proposition.

Engineering maturity, governance completeness, UI quality, or orchestration
capability must not be visually or editorially converted into an efficacy
claim.

## Cohesion rule

Public-facing simplification may:

- reduce jargon;
- reorder explanation;
- improve scanning and visual hierarchy.

It may not:

- invent stronger evidence;
- soften a `NOT AUTHORIZED` boundary;
- omit a material claim limitation;
- imply empirical validation from engineering progress.

## Responsive behavior

The external summary collapses from a three-column composition to a single
column on narrower screens. Its claim ceiling remains visible at every
supported breakpoint.

## Non-effects

This tranche changes presentation and explanatory hierarchy only. It does not
alter governance, authorization, evidence, empirical N, runtime truth, or
scientific state.
