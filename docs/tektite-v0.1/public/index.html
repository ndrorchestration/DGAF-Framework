Tektite v0.1

Public governance console for evidence-bound AI systems.

Tektite shows what happened, what evidence supports it, what claims are currently justified, and what actions remain blocked.

Core question What did the system do, what evidence supports it, and what is it authorized to do next?
Plain-language example A system can finish a task successfully and still remain blocked from the next action if its evidence is stale, incomplete, or outside the allowed scope.

DGAF (Dynamic Governance Agentic Formation) supplies evidence-and-claim governance semantics. ACP (Agent Control Plane) supplies bounded execution-contract semantics. Tektite presents their public-facing state without becoming either authority.

Boundary: This static shell is display-only. It does not execute actions, mutate repositories, mirror private systems, or establish independent validation.
