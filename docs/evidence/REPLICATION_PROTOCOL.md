# DGAF Replication Protocol

1. Freeze repository commit, dependency lock, experiment manifest, and seed family.
2. Record hardware/software environment.
3. Execute the same protocol without changing hypotheses or exclusion rules.
4. Use a distinct seed family for replication.
5. Preserve raw observations and generated artifacts.
6. Compare effect estimates and uncertainty intervals, not only p-values.
7. Record deviations explicitly.
8. Do not label a result independently replicated unless an independent execution satisfies these conditions.
